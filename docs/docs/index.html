General

XAMPHP is a Python command-line application, designed to launch PHP projects via the XAMPP engine from any location on your Windows machine as a virtual local host.

Why use it

  • Any location. Run it in the folder that holds your PHP project; that folder is used as the Apache document root.
  • A real domain. The project opens at the domain you give it instead of localhost/some-folder.
  • Automatic setup. It writes the VirtualHost and the hosts entry so you never edit them by hand.
  • Reset by default. The configuration is reset after stopping the execution.
  • Free. MIT licensed and installed with pip.

Next: see How it works, then Installation. Run your CMD as an administrator to use XAMPHP.

How it works

How it works

When you run xamphp start (domain), XAMPHP follows these steps, taken from its source:

  1. It checks that it runs on Windows and that XAMPP's C:/xampp/xampp_start.exe exists.
  2. It builds a marker from the domain: the domain without its last label, lower-cased, prefixed with xamphp_ (for shop.local that is xamphp_shop).
  3. If XAMPP is already running with a different setup, it stops it first.
  4. It appends a VirtualHost block to httpd-vhosts.conf, with your current folder as DocumentRoot.
  5. It appends 127.0.0.1 plus your domain to the Windows hosts file.
  6. It starts XAMPP, then opens http://domain/phpmyadmin and http://domain in your browser.
  7. When the execution stops, it stops XAMPP, removes the blocks it added and restarts XAMPP if the vhosts file still has content.
your PHP folder
      |
      v
xamphp start shop.local
      |-- httpd-vhosts.conf   + VirtualHost -> your folder
      |-- hosts               + 127.0.0.1 shop.local
      '-- xampp_start.exe     starts XAMPP
                |
                v
   http://shop.local        http://shop.local/phpmyadmin
GeneralInstallation

Installation

XAMPHP is installed from PyPI with pip. XAMPP must already be installed in C:/xampp.

  1. Open CMD and install the package, then restart your CMD:
pip install xamphp
  1. Check that XAMPHP is installed correctly by running its name. It lists the available commands:
xamphp

Run your CMD as an administrator before using XAMPHP. It edits files that normal users cannot write.

How it worksConfiguration

Configuration

XAMPHP has no settings file of its own. Its only option is the domain you pass to start, which defaults to localhost. What it configures are two files:

FileWhat XAMPHP addsWhen it is reset
C:/xampp/apache/conf/extra/httpd-vhosts.confA VirtualHost block marked # <hint>-vhostAfter stopping the execution
C:/Windows/System32/drivers/etc/hostsA line mapping 127.0.0.1 to your domain, marked # <hint>-hostsAfter stopping the execution

Templates

Both entries come from templates in .system/sources. {{hint}}, {{current}} and {{domain}} are replaced with the marker, your current folder and your domain.

# {{hint}}-vhost
<VirtualHost *:80>
    DocumentRoot "{{current}}"
    ServerName {{domain}}
    <Directory "{{current}}">
        AllowOverride All
        Require all granted
    </Directory>
</VirtualHost>
# {{hint}}-hosts
127.0.0.1   {{domain}}   # {{hint}}-host
InstallationCommands

Commands

These are the commands you can use after installing XAMPHP:

CommandWhat it does
xamphpLists the available commands
xamphp start (domain)Starts the project with a virtual domain. Without a domain, localhost is used
xamphp stopStops the project if it did not stop by itself

Example

cd C:\projects\shop
xamphp start shop.local

When it is up, XAMPHP prints the Apache and MySQL (phpMyAdmin) addresses and opens both in your browser.

CommandsProject structure

Project structure

The whole application lives in the .system folder of the repository.

XAMPHP/
|-- .system/
|   |-- index.py            start and stop commands
|   |-- imports.py          shared imports
|   |-- modules/
|   |   '-- localhost.py    VirtualHost and hosts logic
|   '-- sources/
|       |-- vhosts.conf     VirtualHost template
|       |-- hosts           hosts-file template
|       |-- write.bat       admin helper for writing files
|       |-- clight.json     package metadata
|       '-- logo.ico        app icon
|-- .github/workflows/publish.yml
|-- LICENSE
'-- README.md

write.bat is used when the CMD is not elevated: it restarts itself as administrator to copy the new hosts content into place.
