Launch any PHP folder as a local domain, through XAMPP

XAMPHP is a Windows command-line tool that serves the folder you are in through your own XAMPP, on a domain you choose. One command sets it up; stopping it puts the config back.

Features

Everything a local PHP domain needs

XAMPHP does the fiddly Apache and hosts-file work so you only choose a name.

Any folder, one command

Run it inside a PHP project and that folder becomes the Apache document root. No need to move your code into htdocs.

Your own virtual domain

Pick a name like shop.local. XAMPHP maps it to 127.0.0.1 so the project opens at its own address on port 80.

No manual config editing

It adds the VirtualHost block to httpd-vhosts.conf and the entry to the Windows hosts file for you.

Cleans up after itself

By default both files are reset after stopping the execution, so your XAMPP setup is left the way you found it.

Opens it for you

Once XAMPP is up, your browser opens the site and phpMyAdmin on the new domain.

Built on your XAMPP

It does not bundle a server. It starts and stops the XAMPP you already have in C:/xampp.

How it works

From install to browser in three steps

No project files change. Only the two config files XAMPHP manages are touched, and only while it runs.

  1. Install

    Open CMD and run pip install xamphp, then restart CMD. Typing xamphp lists the commands.

  2. Start

    In an administrator CMD, go to your PHP project and run xamphp start with the domain you want.

  3. Browse and stop

    Open the domain in your browser. When you stop the execution, the config files are reset.

Usage

Two commands, one working domain

Install once, then start any project from its own folder. XAMPHP writes a VirtualHost that points at that folder and maps the domain in the hosts file.

  • Leave the domain out and it defaults to localhost.
  • Apache serves the folder with AllowOverride All, so .htaccess files work.
  • Needs an administrator CMD, because it edits protected files.
Command reference 
# once
pip install xamphp

# inside your PHP project folder
xamphp start shop.local
# xamphp_shop-vhost
<VirtualHost *:80>
    DocumentRoot "C:/projects/shop"
    ServerName shop.local
    <Directory "C:/projects/shop">
        AllowOverride All
        Require all granted
    </Directory>
</VirtualHost>
FAQ

Questions, answered

Is XAMPHP free to use?

Yes. XAMPHP is open source under the MIT License, so you can use, copy, modify and distribute it for free. Install it with pip install xamphp.

Does XAMPHP replace XAMPP?

No. XAMPHP drives your existing XAMPP installation. It expects XAMPP in C:/xampp and starts and stops it for you, so XAMPP must already be installed.

Why does it need administrator rights?

To create the virtual domain it edits two protected files: XAMPP's httpd-vhosts.conf and the Windows hosts file. Run your CMD as an administrator before using XAMPHP.

Does it work on macOS or Linux?

Not at the moment. XAMPHP is currently available only for Windows and exits with a message on other systems.

Stop editing config files by hand

Install XAMPHP, run one command in your project folder and open your PHP site on its own domain.
